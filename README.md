# transparencia-municipal-sia

Sistema web para la gestión de transparencia activa y solicitudes SIA en municipalidades. Proyecto académico para el Instituto Profesional San Sebastián.

## Tecnologías

- **Backend:** Node.js v22 LTS, Express 5, TypeScript 5.x, Prisma 7
- **Frontend:** React 18, TypeScript 5.x, Material UI 7
- **Base de datos:** PostgreSQL 16
- **Contenerización:** Docker
- **Control de versiones:** Git + GitHub
